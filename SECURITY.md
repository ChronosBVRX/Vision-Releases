# Seguridad

Si encuentras una vulnerabilidad en Vision+, **no abras un issue público con detalles
explotables**.

Reporta el problema en privado (aviso privado en GitHub o correo al autor) con:

- Qué componente afecta.
- Cómo reproducirlo, paso a paso.
- Versión de la app y del sistema (Android / Android TV).

Se responderá lo antes posible. No se persigue a quien investigue de buena fe.
